AUGUSTINE MUTUA MUSEMBI — PORTFOLIO WEBSITE

Files:
- index.html: responsive one-page portfolio website
- augustine-photo.jpg: portrait displayed on the homepage

Preview:
Open index.html in a browser. Keep augustine-photo.jpg in the same folder as index.html.

Publish free using GitHub + Vercel:
1. Extract this ZIP.
2. Create a new GitHub repository.
3. Upload BOTH index.html and augustine-photo.jpg to the repository root.
4. In Vercel, choose Add New → Project and import that repository.
5. For a plain HTML website, leave the framework preset as Other and deploy.

Before publishing:
- Check that you are comfortable making your phone number and email public.
- Edit index.html in any text editor to change details, colours, or sections.
